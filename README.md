# ✈️ PackJoy 旅程無憂 — 免伺服器純靜態旅行出發清單網站

> **完全不需要伺服器 (No Server Required)**！  
> 純 HTML5 + CSS3 + 原生 JavaScript，只要在電腦上**對著 `index.html` 連按兩下**，即可在 Chrome、Edge、Safari 或任何瀏覽器中直接開啟使用！

---

## 🎯 如何開啟與使用 (How to Open)

1. 打開資料夾：`Travel`（桌面上）
2. 找到檔案：[`index.html`](file:///c:/Users/USER/OneDrive/桌面/Travel/index.html)
3. **滑鼠按兩下直接開啟**（或拖進任一瀏覽器中）即可立即使用！

---

## 🌟 核心特色 (Key Features)

### 1. 🔤 繁體中文與英文雙語並列 (Bilingual Display)
* 每個物品同時顯示 **繁體中文** 與 **English** 名稱及詳細實用備註。
* 頂部隨時可切換 3 種模式：
  * **🌟 雙語對照 (Dual)**：中英並列對照。
  * **🇹🇼 繁中優先 (ZH)**：中文大標、英文小標。
  * **🇬🇧 English (EN)**：英文大標、中文小標。

### 2. 📱 完整的 3C 數位與旅行品項防漏提醒
* **iPhone 智慧型手機** (*iPhone / Smartphone*)
* **iPhone 充電線** (*iPhone Charging Cable - Lightning / Type-C*)
* **iPhone 充電頭 / 豆腐頭** (*iPhone Wall Charger / Adapter Plug*)
* **Apple Watch 智慧手錶** (*Apple Watch / Smartwatch*)
* **Apple Watch 專用磁吸充電線** (*Apple Watch Magnetic Charging Cable - 常忘提醒*)
* **AirPods 降噪耳機** (*AirPods / Noise-Canceling Earbuds*)
* **行動電源 (特別標註：民航嚴禁託運，必須隨身攜帶！)**
* **萬國通用轉接插頭** (*Universal Travel Adapter*)
* 涵蓋 7 大分類：`3C 數位科技`、`重要證件與金錢`、`衣物穿搭與鞋包`、`個人洗沐保養`、`隨身常備藥品`、`航程舒適好物`、`季節戶外特備`。

### 3. 🎒 隨身登機 vs 託運行李 智慧分流
* 物品標註 `🎒 隨身登機`、`🧳 託運行李` 或 `👜 身上小物`。
* **一鍵更換行李位置**：點擊卡片上的行李標籤即可一秒循環切換。

### 4. 💖 行前心情加溫 (Good Mood Booster)
* **✈️ 目的地與倒數計時**：設定旅遊地點與日期，自動換算倒數天數。
* **🌸 旅人療癒勵志小語**：點擊按鈕隨機更換旅行名言錦囊。
* **🎶 互動打勾音效與里程碑慶祝**：
  * 每次打勾都有 Web Audio 原生合成清脆提示音（右上角可切換靜音）。
  * 進度達 50%、75% 彈出彩色彩帶；100% 觸發全螢幕煙火彩帶雨 🎉 與專屬祝賀橫幅。

### 5. 🛠️ 極致便利功能
* **即時模糊搜尋**：支援輸入中英文關鍵字。
* **情境模式切換**：全部、度假、出差、週末輕旅行。
* **分類全選/重置**：一鍵將單一分類打勾或清空。
* **自訂專屬物品**：自由新增私人裝備與數量。
* **一鍵複製文字**：快速複製排版好的清單傳至 LINE 或備忘錄。
* **支援實體紙本列印**：按鍵盤 `Ctrl + P` 或點擊「列印」產出精美實體檢查單。
* **自動儲存 (LocalStorage)**：關閉網頁或重新整理，進度永不消失。
